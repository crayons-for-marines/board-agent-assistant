# board-agent-assistant

Home of the ADO Board Item Agentic Yeoman Azure DevOps extension (`ado-board-agentic-assistant`), which turns release Issue state changes on the dflat-websites board into the release branch, the next Issue, the PR and the release record.

## Documentation

See [`docs/`](docs/README.md) for the release workflow, architecture, development, configuration and troubleshooting guides. The same pages are published to the project wiki.
